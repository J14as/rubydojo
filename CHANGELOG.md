# Changelog

All notable changes to the `rubydojo` gem will be documented in this file.

## [0.1.0] - 2026-06-07

### Added
- Initial release of the `rubydojo` interactive Rails engine gem.
- Mountable Rails engine setup (`Rubydojo::Engine`).
- Interactive Roadmap with visual timeline nodes.
- 7 in-depth Ruby programming lessons (essential syntax, collections, blocks/procs/lambdas, object-oriented concepts, and Rails/ActiveSupport idioms).
- Built-in sandboxed evaluation compiler to run and validate student exercises.
- Professional Royal Red & Beige theme layout.
